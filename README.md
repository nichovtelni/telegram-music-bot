# Telegram Music Bot

Русскоязычный Telegram-бот для поиска треков, официальных аудиопревью и автоматической ленты новинок.

## Запуск

Нужен Node.js 22 или новее. Зависимости не устанавливаются: используется встроенный `fetch`.

Обязательная переменная:

- `TELEGRAM_BOT_TOKEN` — токен из BotFather

Необязательные переменные:

- `SPOTIFY_CLIENT_ID`
- `SPOTIFY_CLIENT_SECRET`
- `YOUTUBE_API_KEY`

Команда запуска:

```bash
npm start
```

## Команды бота

- `/start` — меню
- `/search <запрос>` — поиск
- `/new` — текущие новинки
- `/stream` — включить автоматический поток новинок
- `/stopstream` — выключить поток

Бот отправляет только официальные превью и ссылки на сервисы правообладателей. Он не скачивает и не перепубликует полные защищённые треки.
